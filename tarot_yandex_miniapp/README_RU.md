# Таролог AI на Yandex AI Studio + Telegram Mini App (Windows)

Проект включает Telegram-бота, три карты Rider–Waite–Smith с 3D-переворотом в Mini App, анализ фото клиента мультимодальной моделью Yandex AI и загрузчик полной колоды.

## 1. Что умеет бот

- Принимает вопрос текстом.
- По желанию принимает фотографию отдельным сообщением до вопроса.
- Выбирает три разные карты из колоды 78 карт.
- Показывает их рубашкой вверх в Telegram Mini App.
- Карты можно открывать в любом порядке, с 3D-анимацией.
- После открытия всех трёх Mini App отправляет выбор боту.
- Yandex AI формирует трактовку позиций «Прошлое / Настоящее / Будущее» и общий совет.
- Если клиент прикрепил фото, оно передаётся мультимодальной модели как дополнительный контекст.
- Фото удаляется с диска после обработки расклада. Если расклад не завершён, файл останется до завершения или ручного удаления из `user_photos`.

## 2. Создай ключ Yandex AI Studio

1. Открой https://aistudio.yandex.ru/
2. Создай API-ключ с доступом к Foundation Models / AI Studio.
3. Скопируй **ID каталога (Folder ID)**, к которому привязан сервисный аккаунт. Не используй Cloud ID или Organization ID.
4. Для анализа фото нужна мультимодальная модель. В проекте по умолчанию указана `qwen3.6-35b-a3b`. Доступность модели зависит от каталога и аккаунта.
5. Документация по изображениям: https://aistudio.yandex.ru/ru/docs/ai-studio/operations/generation/multimodels-request

## 3. Настрой Telegram

Создай бота через https://t.me/BotFather или используй существующий токен. Если токен ранее попадал на скриншоты/в переписку, отзови его через `/revoke` и используй новый. Не отправляй токен и API-ключ в чат.

## 4. Настрой `.env`

Скопируй `.env.example`, назови копию `.env` и заполни:

```env
TELEGRAM_BOT_TOKEN=токен_от_BotFather
YANDEX_API_KEY=API_ключ_Yandex
YANDEX_FOLDER_ID=ID_каталога
YANDEX_MODEL=qwen3.6-35b-a3b
WEBAPP_URL=https://ТВОЙ-ЛОГИН.github.io/tarot-miniapp/webapp/index.html
```

Без кавычек и пробелов вокруг `=`. В API-ключе не должно быть кириллицы. Никогда не публикуй `.env`.

## 5. Установи Python и запусти

1. Установи Python 3.10 или новее: https://www.python.org/downloads/windows/
2. Во время установки отметь **Add Python to PATH**.
3. Распакуй архив.
4. Дважды нажми `start_windows.bat`. Скрипт создаст виртуальное окружение и установит зависимости.
5. Оставь окно открытым, пока бот работает.

## 6. Подключи Mini App через GitHub Pages

Mini App должен открываться по HTTPS. Для этого можно использовать GitHub Pages:

1. Создай публичный репозиторий на https://github.com, например `tarot-miniapp`.
2. Загрузи в корень репозитория папку `webapp` и папку `images`. Не загружай `.env`, `bot.py`, токены, ключи или `user_photos`.
3. Открой **Settings → Pages**. Выбери **Deploy from a branch**, ветку `main`, папку `/ (root)`, нажми Save.
4. После публикации адрес страницы будет иметь вид `https://ТВОЙ-ЛОГИН.github.io/tarot-miniapp/webapp/index.html`.
5. В @BotFather выполни `/setdomain` и укажи домен `ТВОЙ-ЛОГИН.github.io`, если BotFather запрашивает домен.
6. В локальном `.env` укажи полный адрес Mini App в `WEBAPP_URL`.
7. Перезапусти бота.

## 7. Скачай колоду из 78 карт

В архиве есть `download_deck.py`. Он получает список файлов из открытого GitHub-репозитория, скачивает карты, проверяет изображения и в конце требует ровно 78 исправных файлов. Запусти:

```bat
.venv\Scripts\activate
python download_deck.py
```

Если GitHub изменит структуру источника, скрипт сообщит, какие карты не найдены. Не публикуй папку `images` в Pages, пока скрипт не покажет `78/78`.

## 8. Как пользоваться

1. Напиши боту `/start`.
2. При желании отправь фотографию отдельным сообщением.
3. Отправь вопрос для расклада.
4. Нажми **Открыть три карты**.
5. Переверни карты в любом порядке.
6. Нажми **Передать расклад боту**.
7. Получи индивидуальную трактовку и общий итог.

Фото привязывается к текущему запросу и удаляется после ответа. Для нового расклада можно отправить новое фото.

## 9. Важные ограничения и безопасность

- Не отправляй фотографии документов, банковских карт, паролей и другой чувствительной информации.
- Не загружай фото на GitHub Pages. Фото идёт через Telegram в локальный бот, а затем в Yandex AI для анализа.
- На GitHub Pages публикуются только HTML и изображения колоды.
- Для анализа фото используется мультимодальная модель. Если модель недоступна в каталоге, выбери доступную vision-модель Yandex AI Studio и укажи её точное имя в `YANDEX_MODEL`.
- В текущей версии расклад хранится в оперативной памяти и сбрасывается при перезапуске бота.
- Если клиент отправил фото, но не завершил расклад, временный файл останется в `user_photos`. Удаляй такие файлы вручную при необходимости.
- Трактовка Таро — символический материал для размышления, не медицинский, юридический или финансовый совет и не гарантированное предсказание.
